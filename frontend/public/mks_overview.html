Executive Overview · Feb 2026

MKS Management System

PT. MITRA KARYA SARANA · End-to-End ERP untuk Steel Fabrication & Marine Contractor

01Ringkasan Sistem

MKS Management System adalah aplikasi manajemen procurement + produksi + kualitas terintegrasi, dibangun spesifik untuk operasional PT Mitra Karya Sarana. Sistem menghubungkan alur bisnis dari Sales Inquiry → Engineering → Purchasing → Store → Quality Control → Finance dalam satu platform, dengan form ISO terdaftar (MCL, MIF, MII) auto-generate PDF.

03Alur Utama: End-to-End Procurement

Fase 1 · Sales & Quotation
CUSTOMER kirim RFQ ↓ SALES input Inquiry (dgn Customer Master autocomplete) ↓ SALES buat Quotation → preview WYSIWYG → cetak PDF letterhead ↓ CUSTOMER approve → SALES upload PO Customer ↓ Sales Order (SO) ter-generate, dikirim ke Engineering → Notifikasi otomatis ke Eng. Head & Staff
Fase 2 · Engineering (BOM)
ENG. STAFF buka SO → buat BOM (line items + qty + material) ↓ Submit ke ENG. HEAD untuk review ↓ ENG. HEAD review: → Approve → BOM Approved, notif ke Purchasing → Revise → kembali ke Staff dgn catatan Shortcut: Eng. Head bisa buat BOM sendiri (skip review Staff) Multi-file upload BOM (drag-drop Excel)
Fase 3 · Purchasing
PURCHASING lihat BOM approved queue ↓ Split BOM ke PO per Vendor (bisa 1 BOM → banyak PO) ↓ Cetak PO PDF letterhead → kirim vendor ↓ Set flag should_stock per item: → true = barang untuk stok gudang (masuk MCL, tidak ke QC) → false = barang untuk produksi customer (masuk MCL + MIF + QC MII) → Notifikasi ke Store saat barang diperkirakan tiba
Fase 4 · Store (Barang Masuk & Keluar)
STORE terima barang dari vendor / customer ↓ Input Incoming Goods (manual atau dari PO): • Pilih Sumber (Supplier / Customer combobox) • Input DO/Invoice + item + qty + so_no • Toggle add_to_stock per item ↓ Auto-generate: • MCL (Material Control Label) PDF — kartu label barang • MIF (Material Issue Form) PDF — form terima • QC Task pending (khusus item non-stok) ⟶ ke QC ↓ STORE keluarkan barang: • Bulk Transaction (batch dari SO) • Consumable Request (dgn approval workflow untuk edit/delete) ↓ Stock Live History per item — FIFO avg cost, IN/OUT ledger, print/export
Fase 5 · Quality Control NEW
STORE input Incoming (item add_to_stock=false) ↓ Auto-buat QC Inspection (status: pending) ↓ QC INSPECTOR buka menu QC → Material Incoming Inspection ↓ Isi form MII (MKS-F-QAD-002 REV 03): • Batch/Grade/Heat No · Mill Cert · Dimention SPEC/ACTUAL • Visual check · Result OK/NG · Remark ↓ Save → status inspected ↓ QC LEADER verify → status verified ↓ Cetak MII PDF (Excel template atau visual editor) NG items ter-track otomatis di dashboard QC (laporan internal)
Fase 6 · Finance & Reporting
FINANCE akses read-only cross-module: • Sales Report (per periode, per sales, per customer) • BOM Cost vs Actual (upcoming) • Incoming Goods Report (semua PO diterima) • Stock Value Report (FIFO) • Backup/Restore (via admin)

04Kelebihan Utama Sistem

A. Business & Operasional

  • End-to-end integration — 1 sistem dari inquiry sampai delivery, tidak ada re-entry data
  • Auto-link antar-modul — SO → BOM → PO → Receive → QC → Stock, semua tersambung by reference
  • ISO Compliance — MCL, MIF, MII generate PDF sesuai form ISO registered (MKS-F-QAD-002)
  • Multi-tier approval — Engineering staff → head, Consumable Request edit/delete via admin
  • Master data terpusat — Customer, SO, User, semua modul share master yang sama (no typo, no dup)
  • Event-based notifications — Bel notif per role saat ada action penting
  • Global search — 1 kotak cari cross-modul (SO, PO, item, customer, quotation)

B. Kualitas Data & Traceability

  • Live Stock History per item — FIFO cost, ledger IN/OUT kronologis, opening/closing balance, filter periode
  • Audit log — Setiap action (create, edit, delete, approve) tercatat dgn user + timestamp
  • Soft-delete — Data dihapus masih bisa di-restore via Trash (tidak hilang permanen)
  • NG tracking — Item yang gagal QC ter-log dgn remark & inspector, siap untuk laporan supplier
  • MCL/MIF/MII tercetak dgn nomor register per receipt (tidak double)

C. Fleksibilitas & Customization

  • Form Template Engine — Admin bisa edit layout MCL/MIF/MII via visual editor (drag element) atau Excel template (download starter → edit di Excel → upload)
  • Sales roster configurable — Filter Sales Name dropdown (Asiong/Nicholas/Kiki/Riska/Feggie/Fiana)
  • Customer autocomplete inline create — Ketik nama → langsung tambah customer baru tanpa buka menu lain
  • Multi-file BOM upload — Drag-drop banyak Excel BOM sekaligus
  • Windows Server 2012 R2 compatible — LibreOffice PDF conversion cross-platform

D. Teknis & Skalabilitas

  • Modern stack — React 19 + FastAPI + MongoDB (industry standard, mudah cari developer)
  • No vendor lock-in — MongoDB self-hosted, tidak butuh cloud database
  • Backup/Restore built-in — 1-klik backup seluruh database (JSON) ke local disk
  • Hot-reload development — Update kode langsung terlihat tanpa restart
  • Offline-ready — Bisa jalan di local network tanpa internet (server + client di LAN)
  • Universal LLM Key ready — Siap integrasi AI (auto-read PO PDF, generate quotation draft, dll)

E. UX & Adopsi User

  • Portal per department — Sales/Store/Eng/Purchasing/QC punya landing page sendiri (tidak overwhelm)
  • Bahasa Indonesia — Semua label & message dalam bahasa lokal
  • WYSIWYG Preview — Preview PDF Quotation & MII persis sama dgn hasil download
  • Responsive — Bisa akses dari desktop, laptop, tablet
  • Keyboard shortcut — Cari global (⌘K), Enter untuk submit, Escape untuk close
